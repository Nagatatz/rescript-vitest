# 新機能の追加

1. **把握**: `README.md` と `docs/repository-structure.md` で全体像とディレクトリ構成を掴む。
2. **既存パターン調査**: Grep で類似機能を探して読み、公開 API の書き方・エラー処理・テストの書き方を確認する（バインディングは `src/*.res`、テストは `__tests__/*_test.res`）。
3. **実装**: 見つけたパターンと `docs/repository-structure.md` の構成に従う。
4. **テスト**: 既存のテストディレクトリに、既存スタイルで正常系・エッジケース（空入力・境界値）・エラーケースを書く。
5. **検証**: `pnpm build && pnpm test`。失敗したら既存パターンとの差を確かめて直し、再実行する。
6. **ドキュメント**: 公開 API を変えたら README と `sphinx-docs/` を更新する（`.claude/rules/documentation.md` に従い、ja の `.po` も更新）。
